## Proof Points

- **Voomi Supply roadmap analog:** phase sequencing that unlocked **~85% publish-time reduction** on **1M+ SKUs**—identity + matching + **multipack/hazmat** before scaling new categories.
- **Profitero:** scale proof **1000+ brands / 1500+ marketplaces**—phase plan must include classifier evaluation (**>95% P/R**) not only syndication milestones.
- **JCPenney:** **Mirakl + SFCC**—early phase must lock **taxonomy alignment** across brands or agent/channel layers inherit debt.
- **Failure scenario:** skipping **compatibility graph** phase → agent answers “fits my unit” queries with **compatibility gaps** → returns spike.
