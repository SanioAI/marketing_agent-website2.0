Marketplace hazmat is **double validation**: your SKU evidence must satisfy **Profitero**-scale classification rigor (**>95% P/R** mindset) *and* each channel’s restricted-product graph. **Compliance Agent** produces evidence bundles; **Channel Matching Agent** context from **Voomi**-style **200M+ ASIN** programs prevents “matched wrong family, wrong hazmat path.”

Same SKU passes internal review but fails **Amazon** hazmat workflow while **Mirakl** path for **JCPenney**-style programs still breaks—no unified evidence model.


## Proof Points

- **Voomi Supply:** **hazmat compliance** in automated scope with **1M+ SKUs** / **200M+ ASINs**.  
- **Profitero:** **1500+ marketplaces** implies many hazmat policy surfaces—classification must be measured.  
- **JCPenney:** **Mirakl + SFCC** marketplace enablement—taxonomy + restriction alignment.  
- **Failure scenario:** ASIN family match correct, hazmat child variation wrong → detail page suppression.
